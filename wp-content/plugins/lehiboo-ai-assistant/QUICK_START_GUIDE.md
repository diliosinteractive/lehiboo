### ÉTAPE 1 : Activer le Plugin (30 secondes)

```
WordPress Admin > Extensions > Le Hiboo AI Assistant > Activer
```

---

### ÉTAPE 2 : Vérifier en Frontend (1 minute)

1. **Ouvrir votre site** (en dehors de l'admin)
2. **Chercher le bouton chat** : rond 💬 en bas à droite
3. **Cliquer dessus** : le chat s'ouvre
4. **Envoyer un message** : réponse démo s'affiche

✅ **Ça marche !** Le plugin fonctionne en mode démo.

## 🎨 PERSONNALISATION (Facile)

### Changer les Couleurs

Éditer dans votre thème enfant :
```css
:root {
  --lehiboo-primary: #VOTRE_COULEUR;
}
```

### Modifier le Message d'Accueil

Éditer `prompts/system-prompt.yaml` ligne "greeting"

### Changer Position du Chat

CSS :
```css
.lehiboo-chat-container {
  right: 20px; /* ou left */
  bottom: 20px;
}
```
